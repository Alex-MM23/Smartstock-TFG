¿Por qué SmartStock AI?

Una plataforma completa que une predicción de demanda, gestión de inventario y comercio electrónico en una sola solución integrada con FastAPI, MySQL y Angular.

Predicción ML Avanzada

Modelo Gradient Boosting entrenado con backtesting recursivo (RMSE 5.29). Predice demanda diaria hasta 90 días con intervalos de confianza del 95%.

Stock de Seguridad Inteligente

Cálculo automático: z · σ · √horizonte. Nivel de servicio configurable (95% por defecto). Alertas proactivas cuando el stock cae por debajo del mínimo.

Tiempo Real MySQL

Sincronización instantánea con base de datos MySQL. Vista materializada v_stock_alerta para consultas ultra-rápidas de estado de inventario.

E-commerce Integrado

Carrito persistente, pedidos con transacciones ACID, historial completo. Autenticación JWT con roles (admin/cliente) y refresh tokens automáticos.

API REST Documentada

OpenAPI/Swagger automático en /docs. Endpoints para salud, stock, predicciones, pedidos y autenticación. Listo para integraciones externas.

Despliegue Docker

Multi-stage builds optimizados. Nginx como reverse proxy con SPA routing y proxy API. docker-compose up y listo: MySQL + API + Frontend.

Cómo funciona en 3 pasos

Desde la conexión de datos hasta la recomendación de compra automática.

1

Conecta tus datos

MySQL almacena productos, histórico de ventas (730 días simulados), proveedores y categorías. La vista v_stock_alerta expone estado en tiempo real.

2

Entrena y predice

Gradient Boosting con features temporales (día semana, mes, fin de semana, promos). Backtest recursivo valida estabilidad. Endpoint POST /predict/demand.

3

Repone y vende

Stock recomendado = demanda total + stock seguridad. Panel admin muestra alertas, pedidos y métricas. E-commerce para clientes finales.
